# 原型与原生界面验收

## 12.1.0.17 当前复核（2026-10-16）

本轮使用 CodeWF.Avalonia `12.1.4.25`，Toolkit 保持 `1.0.0.19`。普通按钮使用正文前景色，实心主按钮继续使用 Semi 的独立配对资源；修复浅色主题部分普通按钮的低对比文字。

正式 Windows x64 发布脚本通过仓外快照执行，只重定向产物、中间目录和开发 NuGet 配置，保留原编译与裁剪参数；NativeAOT 产物、正式 EXE 的 `--verify-runtime` 与原生 UI 验证器均通过。实际界面包含 265 条主断言；新增回归通过真实模板和鼠标事件覆盖八色 × 明暗下的 normal、hover、pressed、恢复状态，共 128 次文字对比测量，最低 7.7218:1，另验证禁用按钮拒绝输入及重新启用后的色值恢复。

当前仓库没有独立单元测试项目；本轮以实际界面的原生回归和运行时自检验证。单文件生成一致性检查通过，浏览器完整审计通过：16 套明暗配色、系统模式变化、四语言、两种宽度及四类更新流程。

本次 README 关键静态 PNG 来自该版本的 NativeAOT 界面验证器。下方保留历史验证记录，版本号、旧安装包哈希及历史 GIF 不能作为本轮新安装器验收结果。当前未执行真实安装、普通桌面拖放或多显示器操作；Linux/macOS 产品运行由各平台继续验收。

# 原型与原生界面验收

2026-10-15，版本 12.1.0.13。主界面保留文件 / 大纲左栏、Markdown 编辑切换、持续可见的脑图及底部操作栏。右侧标题栏使用一个 Ursa 三态按钮、八个配色色点和实际四语言图标列表；单文件原型覆盖相同交互，可复制到空目录离线运行。

## 已执行

- 使用 CodeWF.Avalonia 12.1.4.21、CodeWF.Toolkit 1.0.0.19；统一使用 Toolkit 全局语言单例，应用输出 JSON 覆盖库内嵌同键资源。`atomui` 分支保留旧方案。
- 新标题栏托管离屏验证通过 208 项断言，直接点击 Ursa 内部按钮检查模式保存、配色保留和动态提示，四语言在 980/1280 宽度均无重叠。
- `scripts/publish.ps1 -RuntimeIdentifier win-x64` 成功，应用为 Windows NativeAOT 发布件。
- 12.1.0.12 的 `scripts/ui-verification` 另行发布为 NativeAOT 后实际运行，139 项断言通过，输出 32 张 PNG。包括真实 MindView 节点编辑、撤销重做、Markdown / 大纲 / 脑图同步、八色浅深模式、系统模式、四语菜单、关于和保存窗口动态切语。
- 关于页显示实际应用程序集版本、编译时间、运行平台；更新检查、缺少下载资产、下载校验、手动安装、失败重试、取消及关闭期间取消使用受控服务验证，没有启动真实安装器。
- 无头浏览器遍历原型三态八色、四语言、两种窗口宽度及更新场景。原型和实现均采用 40 px 主标题栏、34 px 窗口按钮及可调左栏。
- Windows EXE 安装器及 SHA256 已本机生成；五平台发布门禁验证安装器与校验文件完整性，拒绝便携压缩包。Linux/macOS 的真实打包和运行交由对应系统 CI 验证。

## 验证边界

上述截图由真实 XAML、ViewModel 和 NuGet 控件离屏渲染，原生验证器使用与产品相同的程序集和裁剪描述。锁屏期间没有操作真实桌面；这不能替代真实鼠标拖动、输入法、多 DPI、多显示器和其他操作系统验收。依赖库仍存在裁剪 / AOT 分析警告，已通过的路径不代表所有反射分支均被覆盖。

开发临时包只通过仓库外 NuGet 配置从 `temp_nugets` 恢复，正式仓库保留公开包版本。

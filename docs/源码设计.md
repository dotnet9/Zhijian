# 枝见源码设计

枝见是一个基于 Avalonia 和 AtomUI 的本地脑图编辑器。仓库把可复用脑图能力和桌面应用外壳拆开维护：`CodeWF.MindView` 只依赖 Avalonia，负责节点模型、脑图控件、迷你图和文件格式编解码；`Zhijian` 是应用工程，负责 AtomUI 主题、窗口、标题栏、大纲视图、Markdown 视图和文件对话框。

## 设计目标

- **模型唯一**：大纲、脑图、Markdown、导入导出都围绕 `MindMapNode` 工作，标题、备注、颜色和子节点只有一份数据。
- **控件可复用**：`CodeWF.MindView` 不引用 `AtomUI.Desktop.Controls`，方便其他 Avalonia 应用直接复用脑图控件。
- **应用负责体验**：`Zhijian` 使用 AtomUI 的窗口、按钮、菜单、文本框和图标，保证桌面应用的主题和交互一致。
- **交互即时同步**：在大纲或脑图任一侧创建、删除、拖拽、编辑标题和备注，另一侧立即反映同一棵树。
- **布局可预测**：节点宽度有最小值和最大值，长标题换行；备注参与高度估算，自动布局时连线不会穿过节点。
- **菜单更顺手**：标题栏的文件和关于入口使用纯文本按钮，文件菜单直接展开导入/导出动作；大纲和脑图菜单补齐同级、升降级和上下移动等常用结构操作。

## 项目组织

```text
src/
  CodeWF.MindView/
    MindMapNode.cs              共享节点模型
    MindMapLayoutMetrics.cs     节点尺寸与布局估算
    MindMapDropPlacement.cs     拖拽落点：前、后、子节点
    MindMapDocumentCodec.cs     Markdown / OPML / XMind 编解码
    Controls/
      MindMapEditor.cs          脑图主编辑控件
      MindMapMiniMap.cs         小图概览控件
  CodeWF.MindView.Themes/
    Themes/Common.axaml         脑图控件默认资源
  Zhijian/
    App.axaml.cs                AtomUI 初始化与主题接入
    Views/MainWindow.axaml      主窗口布局
    Views/OutlineEditor.cs      AtomUI 大纲编辑器

```

## 数据流

`MainWindowViewModel` 持有 `ObservableCollection<MindMapNode> Roots`，当前只允许一个中心主题。大纲视图和脑图视图都绑定同一份 `Roots` 和 `SelectedNode`。

标题或备注变化时，`MainWindowViewModel` 会重新计算布局、刷新统计、同步 Markdown 文本并记录历史快照。树结构变化时，会自动重新订阅新增节点的 `PropertyChanged` 和 `Children.CollectionChanged`，避免新增节点脱离同步链路。

## 脑图控件

`MindMapEditor` 用 `Canvas` 绘制节点和连接线，外层放入 `ScrollViewer`，并通过 `LayoutTransformControl` 实现缩放。节点标题使用 Avalonia 原生 `TextBox`，备注也是原生 `TextBox`，这样 `CodeWF.MindView` 不需要依赖 AtomUI。

非根节点左侧保留一个透明拖拽热区，但不绘制竖线。用户拖动节点时，控件根据指针落在目标节点上方、中部、下方判断是插入到前面、成为子节点、插入到后面，并用虚线预览最终结果。

脑图节点获得输入焦点时，会显示一个轻量悬浮工具条，提供“备注”和“删除”操作。备注输入框只有已有备注或用户显式点击“备注”时才显示；空备注失焦会隐藏，空备注内继续按 Backspace/Delete 会删除备注输入框并回到标题。

## 大纲视图

`OutlineEditor` 属于应用层，因此使用 AtomUI 的 `TextBox`、`MenuFlyout`、`MenuItem` 和 AntDesign 图标。节点前的圆点同时承担菜单和拖拽入口：短按或右键弹出菜单，提供添加子级、添加同级、提升/降级、上移/下移、备注和删除；按住移动超过阈值后进入拖拽，避免短按菜单和拖拽互相抢事件。

大纲备注与脑图备注绑定同一个 `MindMapNode.Note`。没有备注时不显示备注输入框，用户通过圆点菜单添加备注后才显示；如果显示后没有输入内容并切换到其他节点，输入框会自动回收。

## 自动布局

自动布局分两步：

1. `CollectColumnWidths` 递归估算每一层最大的节点宽度。
2. `LayoutNode` 按列宽、水平间距和子树高度计算每个节点坐标。

这样做可以避免第 4 层以后长标题与父节点、连线或输入框互相挤压。节点标题和备注都参与尺寸估算，用户输入长文本时会在最大宽度内换行。

## 小图概览

`MindMapMiniMap` 不再画一份固定示意图，而是直接读取当前节点真实坐标、尺寸和层级，按比例缩放到小图区域。蓝色视口框绑定 `MindMapEditor.ViewportBounds`，点击小图时反算回脑图坐标并滚动到对应位置。

## 格式编解码

`MindMapDocumentCodec` 负责 Markdown、OPML 和 XMind 的导入导出。Markdown 是默认存储形式，标题映射为层级标题或列表，备注写回对应节点内容；OPML 和 XMind 保留标题、备注和层级结构。

## 在新应用中使用 CodeWF.MindView

`CodeWF.MindView` 的目标是作为独立 Avalonia 脑图库复用。新应用只需要引用控件库和主题库，不需要引用 `Zhijian` 应用工程，也不需要 AtomUI。

项目引用示例：

```xml
<ItemGroup>
  <ProjectReference Include="..\CodeWF.MindView\CodeWF.MindView.csproj" />
  <ProjectReference Include="..\CodeWF.MindView.Themes\CodeWF.MindView.Themes.csproj" />
</ItemGroup>
```

在 `App.axaml` 注册默认资源：

```xml
<Application
    xmlns="https://github.com/avaloniaui"
    xmlns:mindThemes="using:CodeWF.MindView.Themes">
    <Application.Styles>
        <mindThemes:MindViewThemes />
    </Application.Styles>
</Application>
```

在窗口或页面中使用脑图和小图控件：

```xml
<UserControl
    xmlns="https://github.com/avaloniaui"
    xmlns:mind="https://codewf.com">
    <Grid>
        <mind:MindMapEditor
            Roots="{Binding Roots}"
            SelectedNode="{Binding SelectedNode, Mode=TwoWay}"
            Controller="{Binding}" />
    </Grid>
</UserControl>
```

`Roots` 是 `ObservableCollection<MindMapNode>`，通常只放一个中心主题。宿主 ViewModel 实现 `IMindMapEditorController` 后，脑图控件就能调用宿主的创建、删除、升级、移动和层级判断逻辑：

```csharp
public sealed class MindMapPageViewModel : IMindMapEditorController
{
    public ObservableCollection<MindMapNode> Roots { get; } =
    [
        new MindMapNode("中心主题")
    ];

    public MindMapNode? SelectedNode { get; set; }

    public int GetLevel(MindMapNode node) => ...;
    public bool IsRoot(MindMapNode? node) => ...;
    public MindMapNode HandleMapEnter(MindMapNode node) => ...;
    public MindMapNode HandleMapTab(MindMapNode node) => ...;
    public bool PromoteNode(MindMapNode? node) => ...;
    public MindMapNode DeleteNode(MindMapNode? node) => ...;
    public bool CanMoveNode(MindMapNode? node, MindMapNode? target) => ...;
    public bool MoveNode(MindMapNode? node, MindMapNode? target, MindMapDropPlacement placement) => ...;
}
```

如果应用需要大纲视图、文件菜单、AtomUI 标题栏或 Markdown 面板，可以直接参考 `src/Zhijian` 的实现。`OutlineEditor` 当前属于应用层，因为它使用 AtomUI 的文本框、菜单和图标；如果新应用也使用 AtomUI，可以复用这部分代码组织方式。

## 主题边界

应用只使用 AtomUI 主题，不使用 `FluentTheme`。`CodeWF.MindView.Themes` 提供脑图控件所需的默认资源，应用层通过 AtomUI 管理窗口、菜单、按钮和输入控件视觉。这个边界保证控件库轻量可复用，同时让枝见应用保持 AtomUI 的整体体验。

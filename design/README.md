# 枝见界面原型

`index.html` 为零服务依赖的可点击原型，直接打开即可。此目录不参与 App 编译。

本轮按已确认的 Semi、Ursa、CodeWF 外壳增补八色配色、独立三态、四语言及关于更新流程，替代旧原型只有暖绿色与固定更新提示的状态。应用继续保留“大纲、Markdown、脑图共享同一模型”的功能：文件与大纲位于左侧，底部切换大纲/Markdown，右侧脑图持续显示，方便边写边观察结构；不再把三种视图设计成互斥的顶层页签。

| 区域 | 设计与实现合同 |
| --- | --- |
| 标题栏 | 40px 高，紧凑菜单；右侧一个三态循环按钮、八个平铺色点及可扩展语言图标菜单，取消模式/配色下拉框 |
| 左侧 | 默认 360px，范围 280—560px；文件、大纲及 Markdown 输入 |
| 中间 | 14px 分隔区，拖拽调整宽度；右侧保留真实脑图视口 |
| 底部 | 状态、撤销、定位、缩放与小图入口 |
| 关于 | 构建属性生成版本与版权、固定样例编译时间、平台与作者；检查、下载、取消、重试与安装状态 |

主题数据按共享 StudioTheme 的颜色令牌固化于 `assets/palettes.json`，不需要其他仓库。原型文案由宿主 JSON 生成，运行：

```powershell
pwsh scripts/sync_design_resources.ps1
pwsh scripts/sync_design_resources.ps1 -Check
npm ci --prefix design/tests
# 首次安装后执行 npx playwright install chromium
npm test --prefix design/tests
```

文件、编辑、视图、帮助、关于提供真实下拉菜单与嵌套子菜单，文案直接使用应用四语言资源。大纲输入、Markdown 标题/缩进列表与脑图共用树模型，支持新增同级/子级、删除、升级/降级、排序、撤销/重做；文件切换保留各自内容与历史。选取 Markdown 或原型 JSON 可载入，保存下载原型 JSON，导出支持 Markdown 与 OPML。三份模板使用应用实际资源，段落说明作为节点备注保留。

主窗体和关于均具桌面边框、40px 标题栏、最小化/最大化/关闭按钮；系统窗口动作仅演示。关于构建时间统一为原型样例 `2026-10-15 00:00:00`，生产程序继续显示真实编译时间。门禁覆盖 16 套配色、系统变化、四语言实际菜单/关于、1240/980 宽度、42 个菜单项、三向节点结构同步、撤销重做、文件草稿隔离、文件载入、OPML 内容、真实指针分隔条和四种更新场景，要求零脚本异常及零外部资源请求。

打开系统文件夹、原生窗口、完整 XMind/draw.io 转换、用户手册/引导及外部网页入口提供明确演示反馈；原型不会访问外部站点或执行安装器。Markdown 解析仅用于结构演示，未实现完整 CommonMark、复杂表格或代码块转树，JSON 是原型格式，不等同生产可编辑格式。字体与布局仍存在差异，未证明视觉保真度达到 95%。

锁屏期间仅执行无头浏览器与离屏检查；字体度量、IME、多 DPI 和系统窗口行为仍需对应桌面环境补验。两库 Demo 的固定原型不受本次 App 原型增补影响。

## 单文件交付

`design/` 中的主 HTML 已内嵌样式、脚本、图标和图片。只复制这一个 HTML 到空目录即可离线查看并操作，无需旁边的资源文件或本地服务。

维护源码放在 `scripts/prototype/`；执行 `pwsh scripts/build_standalone_prototype.ps1` 重新生成，`-Check` 校验生成文件。不要直接修改交付 HTML。交互审计会复制 HTML 到空目录，阻止其他文件和网络资源请求，并检查脚本错误与图片完整性。
